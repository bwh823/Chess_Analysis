# Chess_Analysis
A collection of files that I cleaned and used to conclude information about the Grand Masters, International Masters, and Candidate Masters that were registered by FIDE in 2023. Note that I am writing this README file after I have already concluded all of the steps and processing of this analysis, so steps might be out of order and things might be forgotten. This is a doc where I show why I did certain things with the data as well as how I did things, both for future reference and clarity for whoever wants to look at this as well!

I got the initial dataset from Kaggle using this link:
https://www.kaggle.com/datasets/moinulhossaindhrubo/fide-rated-players?select=fide_active_players_2023.csv 

The raw dataset is listed as 2023_gm_im_cm.csv and the first dashboard I made is called the International Chess Dashboard. To unhide the hidden sheets on the dashboard, right click on your current sheet and select unhide. 


# International Chess Dashboard
The first thing that stuck out to me was that some countries were abbreviated with 3-letters while others weren't. Because I wanted some geographic element with this dataset, I want to make a uniform country column. I made a copy of the dataset, working_file, as to not change the raw data itself, then filtered only the countries that were abbreviated. I copied the filtered country column and pasted it into a new sheet, Countries Abbreviated, and removed the duplicates to get a unique list of abbreviations. I then fed this list into ChatGPT to get the full country names in order, and pasted this next to the abbreviations to set up an xlookup. I also added the non-abbreviated countries to the end of both columns as to fully populate the new country column with a single xlookup. I made a new column in the working file, Country for Map, and used an xlookup with the new column to get full country names. An unknown that I had to deal with was a group of players registering under FIDE the organization rather than a country, so I defaulted those values to Switzerland (as FIDE is based in Lausanne, Switzerland).

Now in Tableau you could use this column immediately to visualize a map of the Grandmasters by taking the country column and the count of Grandmasters in each country, but for the map function to work in Excel I had to create a separate sheet with this information. This kind of took me by surprise because I thought that you could make the map through pivot tables (then I would be able to gather all of my charts on one sheet), but for this I separated the non-pivot table map sheet and the sheet that housed all of my pivot tables.

The last change I made to the working file is adding an age bucket for a visualization of FIDE players and age, as age is much easier to see when you section it off as a histogram. For this I used nested =if() statements with thresholds of 50, 25, and 14-- so 50 and above is old, above 25 but lower than 50 is middle aged, above 14 but lower than 25 is adolescent, and below 14 is a prodigy.

As an excercise, I wanted to also find the rankings of each country in certain KPIs, which was a little harder than just making a pivot table. I used countif() and averageif() functions to gather the counts of each master type and the average standard rating and age of each country, and then ranked them using a dense rank function that I had ChatGPT help me with. This gave me a ranking with no gaps for ties, so if there were three countries tied for 1st then the fourth country would register as 2nd, not 4th. Lastly I formatted each rank to get correct-looking placement formats, like instead of just a numeric "1" in the column I made it "1st". This was a little more tedious as I thought, but that's ok. This whole time I have been copy/pasting value-only cells (you copy and then go to "paste special > values only" once I have the value that I want, like if I had to insert the "1st, 2nd, 3rd" formatting onto an already existing formula that was also referencing the count column which was referencing my working file-- that's a lot of connections! Using values-only allows me the freedom to change incorrect cells at any point in the cleaning process. (Note that I kept the formatting formula because this was the last step that I plan on making in the dashboard and it was on a hidden sheet as well, not seen to any user.)
